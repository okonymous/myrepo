# HapusBG Vercel Preview

This folder contains a browser-side background removal demo. On Vercel, import `okonymous/myrepo` and set Root Directory to `hapusbg-vercel-preview`, Framework Preset to `Other`, and no build command. Account/payment features require a separate persistent backend and database.
